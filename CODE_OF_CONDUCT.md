# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## En bref

- Soyez respectueux, bienveillant et constructif, y compris dans le désaccord.
- Pas de harcèlement, d'insultes, d'attaques personnelles ni de propos discriminatoires.
- Pas de publication d'informations privées d'autrui sans son accord.

## Signaler un problème

Un comportement contraire à ce code peut être signalé de façon confidentielle aux mainteneurs via l'onglet **Security → Report a vulnerability** du dépôt (canal privé), ou via la fonction **Report content** de GitHub. Les signalements sont traités avec discrétion ; les mainteneurs peuvent modérer, masquer ou supprimer tout contenu contraire à ce code.
